# **App Name**: OnFlow

## Core Features:

- Centro de Controle Administrativo: Um painel centralizado para administradores criarem, editarem e organizarem sequências de etapas para para onboarding personalizadas.
- Jornada Dinâmica do Cliente: Uma interface interativa e personalizada de progresso passo a passo para que os clientes acompanhem seu status de onboarding.
- Sistema de Submissão de Evidências: Portal seguro para envio de arquivos e textos, onde os clientes podem carregar documentos necessários para etapas específicas.
- Dashboard de Análise de Progresso: Visão panorâmica para administradores monitorarem o status de conclusão em tempo real e identificarem gargalos.
- Persistência de Dados Global: Armazenamento confiável para todos os modelos de onboarding, funções de usuário e métricas de progresso.

## Style Guidelines:

- Cor Primária: Vermelho Sofisticado (#D32F2F) para ações principais e presença de marca.
- Cor de Fundo: Bege Suave (#F5F5DC) para proporcionar um ambiente acolhedor, profissional e de fácil leitura.
- Cores de Destaque: Branco Limpo (#FFFFFF) para cartões de conteúdo e Cinza Ardósia (#757575) para elementos secundários e bordas.
- Pareamento de fontes: 'Poppins' para títulos visando um visual moderno e 'Inter' para o corpo do texto para máxima legibilidade.
- Layout modular estruturado com componentes em cartões e uma barra lateral fixa para navegação intuitiva entre perfis.
- Micro-transições suaves em barras de progresso e efeitos de fade ao alternar entre as visões de admin e cliente.
- Iconografia minimalista de linhas finas para diferenciar estados de tarefas: pendente, em revisão e concluída.
